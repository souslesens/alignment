# alignement

SousLeSens Vocables plugin for aligning classes across sources (e.g. CFIHOS-IOF ↔ UNSPSC):
ElasticSearch candidate matching, exact/non-exact split, `owl:equivalentClass` /
`rdfs:subClassOf` generation, and LLM classification of the non-exact matches.

Forked and renamed from the `panorama` plugin; runs as an independent plugin.
